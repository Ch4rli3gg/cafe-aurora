# Café Aurora

Sitio web responsive para una cafetería ficticia, desarrollado con HTML y CSS.

## Tecnologías

- HTML5
- CSS3

## Características

- Diseño responsive
- Sección de inicio
- Información sobre el café
- Menú de productos
- Sección de contacto
- Botón de contacto mediante WhatsApp
- Optimización de imágenes
- Publicación mediante GitHub Pages

## Demo

[Ver Café Aurora](https://ch4rli3gg.github.io/cafe-aurora/#inicio)

## Estructura

```text
cafe-aurora/
├── Images/

```

## Objetivo

Proyecto desarrollado como práctica de diseño y desarrollo web,
con enfoque en sitios pequeños para negocios locales.
